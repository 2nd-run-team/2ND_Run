# Git LFS 2 editor plugin

Vendored from [ProjectBorealis/UEGitPlugin](https://github.com/ProjectBorealis/UEGitPlugin) at commit `30402ac4cdd9f8d9369c948ea4f3b9f5be9bc313` (2026-08-09, `dev`). Licensed under the included `LICENSE.txt` (MIT).

This Windows project includes the upstream plugin descriptor, `Source/`, `Resources/`, and the Windows `git-lfs.exe` required by its build rules. The macOS and Linux executables are omitted.

Use the plugin for editor asset status and Git LFS file locks. Keep branch changes, pulls, commits, and pushes in the team's Git/PR workflow; the upstream in-editor Pull may rebase, and in-editor Submit may push directly.
